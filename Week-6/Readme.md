This Week 6 experiment ([`Week-6`](https://github.com/jashh03/GEN-AI_2520030386/tree/main/Week-6)) focuses on evaluating LLM output quality against a curated benchmark dataset. Using [`Golden_set.json`](https://github.com/jashh03/GEN-AI_2520030386/blob/main/Week-6/Golden_set.json) as the ground-truth reference, [`main.py`](https://github.com/jashh03/GEN-AI_2520030386/blob/main/Week-6/main.py) runs test prompts through the model and logs performance metrics into [`baseline_results.csv`](https://github.com/jashh03/GEN-AI_2520030386/blob/main/Week-6/baseline_results.csv). Required dependencies are kept organized in [`requirements.txt`](https://github.com/jashh03/GEN-AI_2520030386/blob/main/Week-6/requirements.txt) for straightforward setup. Together, this pipeline establishes a measurable baseline for tracking model accuracy and consistency over time.
