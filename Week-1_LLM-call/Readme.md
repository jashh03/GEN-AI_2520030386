This Week-1 experiment covers the basics of connecting to a Large Language Model API using Python.Inside "main.py", the script sets up the API client,
safely loads credentials from environment variables, and sends a prompt to generate a text response. Along the way, 
it highlights key essentials like handling API keys without hardcoding them, parsing the returned output, and keeping dependencies organized 
in "requirements.txt". Overall, it serves as a simple starting point for integrating generative AI into a Python project.
