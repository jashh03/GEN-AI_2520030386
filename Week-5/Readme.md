This Week 5 experiment ([`Week-5`](https://github.com/jashh03/GEN-AI_2520030386/tree/main/Week-5)) focuses on managing and enforcing token or cost budgets for LLM usage. Inside [`budget.py`](https://github.com/jashh03/GEN-AI_2520030386/blob/main/Week-5/budget.py), the implementation tracks spending against predefined limits so API calls stay within budget, while [`test_budget.py`](https://github.com/jashh03/GEN-AI_2520030386/blob/main/Week-5/test_budget.py) verifies that threshold checks and alerts trigger accurately. Required packages are kept organized in [`requirements.txt`](https://github.com/jashh03/GEN-AI_2520030386/blob/main/Week-5/requirements.txt) for straightforward setup. Altogether, it adds an essential layer of cost control for running generative AI applications safely.
