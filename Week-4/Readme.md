This Week 4 experiment explores how different tokenizers break down and process input text. Inside "tokenizer_comparison.py", the script compares tokenization strategies side by side—looking at how text is split into subwords, token counts, and encoding differences across models. Key takeaways include understanding why token efficiency directly affects API costs and context window limits, with required libraries listed in "requirements.txt". Overall, it provides practical insight into how raw text is translated before an LLM ever processes it.
